# Rating Engine — Convergence Report

This report is generated by `src/engine/convergence.test.ts`. It simulates a user of a fixed _true_ skill answering 100 puzzles. Each served puzzle is rated at the user’s current tracked rating (the pool-matching assumption), the user answers correctly with probability `expectedScore(trueRating, puzzleRating)`, and the tracked rating updates after every attempt via `updateRating` using the real K-schedule (32 for the first 20 rated attempts, then 24) and the 400 floor. Coin flips come from a seeded mulberry32 PRNG, so the numbers below are fully deterministic.

Every tracked rating starts at 1200 (the real new-user value). A scenario passes if the final tracked rating lands within ±75 of the true rating.

Regenerate with:

```
pnpm vitest run src/engine/convergence.test.ts
```
